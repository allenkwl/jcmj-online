# 單機存檔：十格＋功業簿

> 2026-09-25 與使用者定案，v1.30 起。資料層在 `src/solo-slots.js`（測試 `test/solo-slots.test.js`），
> 畫面在主程式「接續戰役」那一段。連線版的十格存檔是另一套（`src/online-campaign.js`、`docs/online-campaign.md`），兩邊不共用資料。

## 一、為什麼要改

以前的單機是「每一國一份戰役」（`mj4.campaigns.v2`），而且**只在一場四局打完時才存**：

- 打到一半關掉，那一場打過的局、分數全部不見
- 沒有「繼續」入口，要記得選同一國才會接上
- 一國只能有一份

## 二、定案

| 項目 | 做法 |
|---|---|
| 標題畫面 | 由左往右三顆一樣大：**開始征途｜接續戰役｜連線對戰**。有存檔時焦點預設在「接續戰役」；沒有存檔時它反灰寫「尚無」 |
| 格數 | 十格，一格＝一段征途（選國到統一天下）。同一國可以開好幾格 |
| 開始征途 | 播序章 → 選國 → 出兵時開一格新的。**十格滿了先擋下來**，請玩家到接續戰役刪一格 —— 系統不會擠掉任何一格 |
| 接續戰役 | 十格列表，最近玩的在最上面、焦點預設停在它，點一下接著打 |
| 什麼時候存 | **每打一張牌就存**（整個牌局，連點太快時 300ms 合併一次；切到背景、關分頁時立刻存） |
| 回來停在哪 | **離開時的那一手**。不退回局首 —— 否則抓到爛牌重新整理就能重發 |
| 還沒押注的那一局 | 回來會重新跑發牌動畫與占卜（押注本來就還沒決定） |
| 兩場之間 | 一場結算完那一格就不再帶牌局，繼續時直接開下一場（不再經過序章與選國） |
| 重整旗鼓換國 | 留在同一格，照 `CP.repick` 帶走 boost 與場數 |
| 刪除 | 只有玩家按兩下確認才刪 |
| 離開牌局 | 單機的確認框寫「已自動存檔」；離開時把牌局收起來（不然換視窗大小一重畫，電腦會在標題畫面底下繼續打） |

## 三、統一天下 → 功業簿

- 統一的那一刻（結算時）**先記進功業簿**，名字預設君主稱號，同時空出那一格存檔
- 動畫播完跳出「留名」：可以改成自己的名字（最多 12 個字），按「略過」就維持君主稱號
- **一定記錄，名字可以不寫**。使用者原本提議「不寫名字就不存」，討論後改掉：記錄幾乎零成本，
  但留名框開著時斷電、切走、按錯，都會變成「沒存」，也違反「系統不能主動刪記錄」
- 功業簿在「接續戰役」畫面的第二個分頁（標題畫面維持三顆按鈕）。點一筆可以改名字，刪除要按兩下

## 四、舊存檔

第一次載入時搬一次（`SS.migrate`，標記 `migrated`）：

- `mj4.campaigns.v2` 每一國的戰役 → 一格（連還沒打完第一場的也搬）
- 已統一的、`history` 裡的 → 功業簿，名字用君主稱號，標「舊紀錄」
- 沒有 v2 時搬更舊的 `mj4.campaign.v1`
- **兩個舊 key 一個字都不動**，之後也不再寫它們（舊版遊戲檔打開看到的是搬家前的樣子）

## 五、資料形狀

```
localStorage['mj4.solo.v1'] = {
  slots: [{ id, kingdom, level, camp, snap, createdAt, updatedAt }],
  fame:  [{ id, name, lord, kingdom, matches, conquered, unifiedAt, migrated? }],
  migrated: true
}
snap = { match, waiting, foes, seatInfo, seeding, skill, betHandNo }   // null＝兩場之間
```

`match` 本來就是純資料，整份存；`ctx` 裡的 AI 函式不存，接回來時用 `AI.flowHooks()` 重建。
沒有 `curSlot` 就不存 —— `MJDev.quickStart`、對戰畫面編輯器（`#preview`）都不會碰到任何一格。
