# 問題反應與意見諮詢（v2.07）

2026-10-25 使用者：「在說明裡加入一欄讓玩家反應問題的功能，就是問題反應與意見咨詢，放最上面，反應的問題填入 firebase，我們之後要來處理意見反應」
「我們處理後是否也可以寫回 firebase 該玩家上線就可以看到？」→ 定案：「1. 可以（改規則、部署） 2. 好（自動附資訊） 3. 只有我（管理者）」。
用語：對玩家說話用「您」（「介面上 我的意見 保留，把你改您，客氣些」）。

## 一、玩家這一邊

| 位置 | 內容 |
|---|---|
| 說明面板**最上面** | 「問題反應與意見諮詢」一段＋「✍ 反應問題／提出意見」鈕（方向鍵／手把打開說明時焦點就在這顆） |
| 意見面板 `#fb-ov`（疊在說明上面） | 分類（問題回報／意見建議／其他）、內容（≤1000 字，字數即時顯示）、聯絡方式（選填）、送出、「我的意見」清單 |
| 新回覆提醒 | 說明鈕 `#hud-help`、面板入口鈕亮紅點；**標題畫面**出現「📬 您反應的意見有新回覆」（說明鈕只在牌桌上看得到，所以標題畫面另外提醒） |

- **單機也能送**：送出那一刻才連 Firebase（匿名登入）。沒送過意見的這台完全不連線。
- 一分鐘內只能送一次（本機記時間，按鈕倒數）。
- 送出時自動附上（面板上寫明附哪些）：版本、瀏覽器 UA、螢幕／視窗大小、單機／連線／觀戰、桌名、是不是開桌的、第幾局、牌山剩幾張、國家、登入方式、**最近 5 筆 JS 錯誤**（`src/feedback.js` 一載入就開始記）。
- 回覆什麼時候看得到：**送過意見的這台**開遊戲 3 秒後讀一次自己的意見；打開說明、意見面板時也讀。回覆時間比「看過的」新 → 紅點＋標題提醒；打開意見面板看過就消失（`localStorage` 的 `jcmj_fb_seen`）。
- ⚠️ 匿名身分只存在這個瀏覽器。換裝置、清網站資料，就讀不到以前的意見。**登入（Google／Email）後送的**跟著帳號走，換裝置也看得到。面板上會依登入狀態提醒。
- 鍵盤／手把：焦點落在輸入框按確定＝開始打字；打字中按 Tab 離開輸入框；B 先關意見面板，再關說明。
  （`onCancel` 裡意見、說明排在奏章／天下形勢／占卜前面 —— 它們疊在最上層。）

## 二、資料與規則

```
/feedback/{uid}/{推送 key} = {
  cat: 'bug'|'idea'|'other', text(≤2000), contact?(≤200), at(伺服器時間), ver, name?, info(JSON 字串 ≤4000),
  status?: 'seen'|'replied'|'done', reply?(≤4000), replyAt?      ← 這三個只有管理者能寫
}
/admins/{uid} = true          ← 網頁寫不進去，只能用 firebase CLI
```

- 玩家：只能**新增**、讀自己名下的；不能改、不能刪、不能寫 status／reply。
- 管理者（`/admins/{uid} === true`）：讀全部、寫回覆與狀態、刪除。
- 管理者名單放資料庫而不寫死在規則裡 → 換帳號、加人都不用重新部署規則。
- 規則測試：`tools/rules-test/rules.test.mjs` 第 10 段；`tools/db-janitor.py` 把 `feedback`、`admins` 列為全域資料（不當垃圾）。

加管理者：

```bash
firebase database:set /admins/<uid> --data true --project jcmj-4p -f
```

## 三、管理頁：`devtools/意見反應v0.1.html`

- 用遊戲裡同一個 Google／Email 帳號登入；還不是管理者時顯示 uid 與上面那行指令。
- Google 登入只在 Firebase 允許的網域能用：`jcmj-4p.firebaseapp.com`、`jcmj-4p.web.app`、`allenkwl.github.io`、`localhost`
  （localhost 是 2026-10-25 加的 —— 從啟動台開按 Google 登入失敗）。⚠️ `127.0.0.1` 不在裡面，要用 `localhost` 開。
- 清單即時更新；篩選：未處理（新的＋已讀，預設）／新的／已回覆／已處理／全部、分類、搜尋。
- 每則：送出回覆（status 自動變「已回覆」）、標為已讀、標為已處理、刪除；附帶資訊可展開。
- 用**獨立命名的 Firebase app**：在管理頁登入／登出，不會換掉同一個瀏覽器裡遊戲的身分。
- 跟著 push 上 GitHub Pages 沒關係：別人打開、登入了也讀不到任何東西。
- `?emu=1` 連本機模擬器。
