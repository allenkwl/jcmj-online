## 比例：同一個鏡頭

- 直的那一組：240 px＝牌寬 26 mm；橫的那一組：240 px＝牌長 35 mm
- **水平面一律壓縮 0.78**（躺著的頂面、立著的頂端都一樣）；垂直面照躺著那張的前緣換算（直 4.5、橫 3.35 px/mm）
- 所以側立牌的**頂端（牌寬 26 mm）跟躺著的橫牌頂面一樣高（139）**，左右兩家一列往下排時每張前進的距離跟躺著時相同；
  寬只有厚度（137，比躺著窄）—— v2 把厚度拉成跟牌長一樣寬是錯的
